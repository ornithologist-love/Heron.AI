# Notion Connector

从左侧导航打开 **连接器 → Notion**，点击连接后在浏览器登录 Notion 并授权。

连接后，卡片详情显示官方服务返回的完整工具清单。会话用 `search_mcp_tools` 按需查找和加载工具。可用工具和内容取决于 OAuth 授权及账号和工作区权限。 [Notion 官方 MCP](https://developers.notion.com/guides/mcp/get-started-with-mcp)

卡片图标随包交付，来自 [Notion 官方站点](https://www.notion.so/images/favicon.ico)。
