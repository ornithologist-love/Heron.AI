# custome-theme

Heron.AI 自定义主题。默认启用，可在支持插件管理的聊天中要求关闭或重新启用 `custome-theme`。曾安装个人主题的用户可从插件管理器移除旧插件。

- 正文使用本地 Google Sans。Windows 代码字体优先 Consolas，macOS 优先本地 IBM Plex Mono。中文继续使用系统字体。
- 正文默认保持 14px。未单独设置代码字号时，代码块使用 12px，行内代码使用 13px。手动字号设置优先。
- 启用时调整浅色和深色界面的表面对比、边框、圆角和代码样式。停用时撤销样式覆盖。

两款字体使用 Google Fonts 的原始 Latin 和 Latin Extended WOFF2 文件。字体与授权文本随包提供，见 [Google Sans](assets/google-sans/OFL.txt) 和 [IBM Plex Mono](assets/ibm-plex-mono/OFL.txt)。
