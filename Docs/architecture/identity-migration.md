# 产品身份与用户数据迁移

Heron.AI 采用独立的产品标识体系：程序集与命名空间前缀为 `HeronAI`，运行时目录与插件前缀为 `heron-ai`，环境变量前缀为 `HERON_AI_`，默认状态目录为用户主目录下的 `.heron-ai`。

## 旧身份由分发方声明

公开运行时只提供通用的改名迁移引擎（[legacy-identity.mjs](../../packages/common/runtime/src/heron-ai/migration/legacy-identity.mjs)），源码里不知道任何旧产品名，也不以编码、混淆或本地未入库的映射表保存旧名。

- **描述文件随分发包交付**：改过名的分发方在自己的插件包 `package.json` 里声明 `heronAi.legacyIdentity`，指向包内的 JSON 描述文件，列出旧状态目录、旧聊天目录、旧本机安装目录、精确标识映射、前缀规则、状态内改名、旧 profile 包名、旧清单字段和旧预设前缀。
- **读取时机与范围**：迁移在用户的 profile 选择加载之前运行，所以描述文件来自本载荷随包插件清单列出的全部随包插件，不论是否启用；用户自行安装的插件不参与。
- **约束**：`version` 必须为 1，未知字段、越出包目录的路径、符号链接、带 `..` 的状态内路径、包含换行的值都会让启动失败；两个包对同一旧标识给出不同新名同样视为错误。
- **匹配顺序**：先精确映射，再按声明顺序匹配前缀规则。
- **没有描述文件就没有迁移**：公开构建不带任何描述文件，迁移整体是空操作，不扫描用户主目录。

## 状态目录与聊天数据迁移

- **默认目录迁移**：默认状态目录 `.heron-ai` 尚不存在时，启动器在加载插件组合前把描述文件列出的第一个现存旧状态目录原子重命名迁入；后续步骤失败会把目录改回原名。调用方显式指定了自定义状态目录时不扫描用户主目录。
- **保留原有记录**：原生会话 ID、日志文件、工作区目录和凭据内容均保持原样，不因产品改名而改写格式。旧聊天记录合并保留；同名文件内容不同时以内容哈希后缀另存。

## 配置与凭据兼容

- **精确映射已知标识**：仅对已知的产品配置项（插件开关、主题选择、凭据引用、生成的 profile 包引用）在首次启动前做标识转换；若新版标识已存在，则优先保留用户的新设置。未知插件的配置不做全局文本替换。
- **安全写入**：所有被改写的配置文件均先生成原始备份再原子替换；凭据文件仅追加新的引用别名，完整保留原有引用与记录。
- **预设与缓存**：旧会话使用的产品预设通过隐藏别名继续解析，无需重写历史会话事件；旧预设前缀参与组合缓存键，描述文件变化后组合自动重建。迁移完成后再次启动不会重复改写配置。

## 开源与宿主解耦边界

公开产品可独立构建和运行；各外部宿主、团队私有插件及更新服务仍由各自的交付方独立维护，其旧名只出现在交付方自己的描述文件里，不与公开产品的改名强绑定。
