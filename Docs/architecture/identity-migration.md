# 产品身份与用户数据迁移

Heron.AI 使用独立的产品身份：程序集与命名空间为 `HeronAI`，运行时目录与插件行前缀为 `heron-ai`，环境变量为 `HERON_AI_`，默认状态根为用户目录下的 `.heron-ai`。兼容表使用十六进制编码保存旧标识，在读取历史数据时解码，公开源码不保留旧品牌字面量。具体映射集中在本地可选的 `legacy-identifiers.json`，兼容读取只存在于该表与 [迁移模块](../../packages/common/runtime/src/heron-ai/migration/branding.mjs)。

默认状态目录不存在时，启动器在读取产品组合之前迁移旧状态根；调用方显式指定其他状态目录时不会扫描用户主目录。原生会话 ID、日志、工作区目录和凭据内容不随产品名称改变。旧聊天文件合并留存，冲突文件用内容摘要区分；迁移不改写聊天格式。

配置迁移只映射已知的产品标识。插件开关、主题选择、凭据引用和生成的 profile 包引用在首次启动前调整；新标识已经存在时保留用户的新设置。每个改写的配置文件先保存原文备份，再原子替换；凭据只添加新引用别名，保留旧引用和记录。未知插件的配置不作全局文本替换。

旧会话使用的产品预设通过隐藏别名继续解析，避免为改名重写会话事件。生成的组合与运行时缓存由新版重建，保存过的插件路径重新绑定到当前组合。迁移完成后重复启动不再改写已经迁移的配置。

公开产品可独立构建和运行。具体宿主、团队私有插件与更新服务仍由各自的交付方维护；这些消费方的切换不隐含在公开产品的改名中。
