# 模型目录与执行接入

模型目录说明可选渠道、模型和能力；执行集成负责认证、传输和实际调用。二者分开，目录中没有用户令牌。公共载荷没有团队渠道默认值，仍可使用底座支持的模型和用户自行配置的渠道。

可选插件贡献部署目录和集成入口。启动时先确定插件选择并读取内容，再准备渠道和界面，避免页面展示一种渠道、实际执行却使用另一种。提供器 ID、模型 ID 和集成归属保持稳定；同一部署文档有多个来源时直接报错。

凭据存储由当前实例管理，集成只持有引用和生命周期。插件停用撤销路由、登录和联网入口，保留用户已有凭据；重新启用后恢复贡献。启动时确定的目录和默认策略在重启后重建。无关插件不读取或回退到其他渠道的令牌。

远程模型服务和企业认证属于部署方，客户端只消费明确的目录地址和集成配置。公共源码不包含工作区中的私有服务。

客户端命名与远程目录可以独立升级。部署内容可通过 `modelFieldAliases` 将旧模型能力字段映射到当前字段；规范字段优先，别名仍经过同样的类型与范围校验。具体旧字段名由部署插件提供，公共运行时不绑定某个团队的服务协议。
