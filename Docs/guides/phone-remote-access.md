# 远程会话与机器接入

公共 Heron.AI 不内置机器登记、SSH 连接、远程导航或手机发布客户端；这些实现连同服务器由 Team 集成包维护。公共层提供宿主协议和插件装配机制，不预设服务地址或企业身份。

接入方通过已启用插件贡献宿主配置、远程模块和服务连接。宿主 ID 只选择实现，不赋予机器访问权限；访问策略与凭据由接入方及其服务端维护，公共层不按机器名或产品版型推导权限。

远程接入不改变执行归属：工作区、会话、工具与权限始终由目标 Host 持有。实现远程能力的插件应复用目标 Host 的原生协议，不复制出另一套会话执行器。扩展方式见[扩展边界](../architecture/extensions.md)。

## 机器登记与恢复

机器身份、重连与恢复由远程集成包负责，公共运行时不维护机器登记状态。

## 远程机器配置面板

机器配置页由集成包提供；公共插件管理器负责其启停与组合。

## 体验统一工作区

远程入口应按 Host 和工作区 ID 定位原会话；同名工作区不能被当作同一份数据。公共运行时保留本机工作区与会话机制，不附带跨机器目录。
